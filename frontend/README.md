# RDC GYM Frontend

Vite + React frontend with simple login and role-based routes.

Quick start:

```bash
cd frontend
npm install
npm run dev
```

Notes:
- The login page attempts to load the logo from `/lib/logo.png` (please place your logo at `lib/logo.png` in the workspace root). If you prefer, copy the logo to `frontend/public/logo.png`.
- API base: `http://localhost:4000` by default. To change, set `VITE_API_BASE` in `.env`.
